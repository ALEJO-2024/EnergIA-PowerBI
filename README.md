## 📌 Descripción del Proyecto
**EnergIA** es una solución de Business Intelligence enfocada en centralizar y analizar la operación de distribución de energía eléctrica en Antioquia. A partir de información fragmentada de clima, infraestructura de red, suscriptores y tarifas, este proyecto transforma datos dispersos en indicadores claros para la toma de decisiones oportunas ante contingencias.

Este repositorio contiene el desarrollo estructurado bajo el formato **Power BI Project (`.pbip`)**, permitiendo el control de versiones del modelo semántico, las definiciones del reporte, el análisis exploratorio (EDA) y los pipelines de datos.

---

## 📊 Métricas e Indicadores Principales (2021)
* **Impacto Financiero:** $432 mil M COP en pérdidas operativas por interrupciones analizadas.
* **Continuidad del Servicio:** 74,25% de cumplimiento operativo.
* **Efectividad de Resolución:** 86,10% de cierre efectivo de incidencias.
* **Correlación Climática:** 24,18% de fallas vinculadas a picos de precipitación pluvial.
* **Municipios de Mayor Criticidad:** Medellín, Bello, Caucasia y Apartadó.

---

## 🛠️ Herramientas Utilizadas
* **Visualización y Modelado:** Microsoft Power BI Desktop (`.pbip`), DAX, Power Query.
* **Preparación y Análisis:** Python / SQL para análisis exploratorio (`eda`) y estructuración de datos (`pipeline`).

---

## 📁 Estructura del Repositorio
* `dashboard - power bi.pbip` — Archivo principal del proyecto de Power BI.
* `dashboard - power bi.Report/` — Definición visual, páginas y configuraciones del tablero.
* `dashboard - power bi.SemanticModel/` — Modelo de datos, relaciones y medidas DAX.
* `eda/` y `pipeline/` — Scripts y flujos de exploración y preparación de datos.
* `base-de-datos/`, `datos finales/` y `datos-reportes/` — Conjuntos de datos procesados y tablas de soporte para el modelo.
* `aplicacion/`, `generacion/` y `muestras/` — Recursos complementarios y muestras de validación.
* `docs/` — Documentación técnica y presentación ejecutiva del proyecto.
